Desktop screenshots use a 1440 by 1000 viewport. The mobile variants use a 390 by 844 Android-sized Chromium viewport. Component screenshots preserve the application's actual controls and proportions; WebP encoding reduces asset size. The presence and BreakGate screenshots show the actual components at isolated demonstration timer boundaries. Coach content is demonstration reflection data rendered by the real Coach page.

The related full-page previews are in `public/showcase/current`. When changing a pictured control, recapture the affected desktop and mobile views and update the guide text together. Avoid recreating the interface in a separate mockup.
